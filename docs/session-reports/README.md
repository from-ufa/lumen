# Session reports

После **каждого** выполненного промпта агент сохраняет краткий отчёт в этот каталог.

## Имя файла

```text
YYYY-MM-DD_HHMM_<short-slug>.md
```

Пример: `2026-07-29_1203_session-reports-convention.md`

## Что внутри

1. Промпт / задача (кратко)
2. Что сделано
3. Файлы / коммиты / SHA
4. Проверки (health, git)
5. Откат (если применимо)
6. Риски / next steps

Крупные фазы (Phase 1, deploy) дополнительно живут в `docs/ios*.md`.

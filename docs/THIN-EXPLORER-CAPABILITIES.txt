FEED SHAPE (for any future UI)
------------------------------
GET /api/chain/feed returns particles + optional address focus + tip meta.

Particle stages (data tags only — not a visual design):
- mempool     = unconfirmed
- assembling  = in tip formation (if used by feed)
- sealed      = already in tip block
- focus       = address-owned ERG/tokens (address focus mode)

Normalization:
- ERG = sum of output values (nanoERG)
- tokens = aggregate assets across outputs by tokenId
- performance caps: particles per feed, tokens per tx, names resolved per feed
- feed may include txGroups[] for per-tx inputs/outputs/erg/tokens

Token naming:
- prefers node token name (e.g. AUGERG, ERGUSD-NFT)
- fallback short id xxxx…yyyy

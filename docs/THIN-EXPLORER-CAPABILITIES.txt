- Built for product UI / visualization

WHAT IT IS NOT

BACKEND CAPABILITIES
--------------------
STATUS
- node name, network, fullHeight, headersHeight
- indexedHeight
- peersCount, unconfirmedCount
- confirms source is local

BLOCKS
- recent N blocks by height
- block by header id OR height
- fields: id, height, timestamp, size, txCount
- each tx: id, input/output counts, total ERG nano, tokens[{tokenId, amount}]

MEMPOOL
- unconfirmed txs from local node
- same normalized shape as confirmed
- pending flag for visualization

ADDRESS
- confirmed nanoERG balance
- token balances: tokenId, amount, name, decimals (when node provides)

TOKEN METADATA
- name, decimals, description, emission (as node provides)
- in-process server cache of token names (process lifetime, capped size)

FEED (main product endpoint for viz)
- tip + recent blocks
- mempool txs
- particles[] flattened for 3D
- optional focus address snapshot
- tokenNames map { tokenId: displayName }
- source, heights, generatedAt


PARTICLE MODEL (for visualization / next UI)
--------------------------------------------
Each particle:
- kind: "erg" | "token"
- stage: "mempool" | "assembling" | "sealed" | "focus"
- tokenId? label, name?, amount
- color (stable hash from tokenId; ERG = brand orange #FF7A3D)
- txId, pending, weight (0..1 size hint)

Stages:
- mempool     = unconfirmed, outer orbit, brighter
- assembling  = pull-to-core on new tip pulse
- sealed      = already in tip block
- focus       = address-owned ERG/tokens (address focus mode)

Normalization:
- ERG = sum of output values (nanoERG)
- tokens = aggregate assets across outputs by tokenId
- performance caps: particles per feed, tokens per tx, names resolved per feed


CHAIN PULSE UI CAPABILITIES
---------------------------
DASHBOARD
- third viz tab: NETWORK ORBIT | CHAIN PULSE | WORLD MAP
- live poll ~4s (react-query)

VISUALIZATION
- soft circular additive sprites (gaussian falloff, not hard mesh balls)
- mempool particles: outer bright orbit
- sealed particles: inner orbit from tip txs
- assemble pulse on new tip: pull + camera dolly
- sealed stack: recent block discs under core
- soft block core (icosahedron + wire + ring + lights)
- stars / fog / nebula depth
- optional soft chime on new tip (SOUND ON/OFF)

ADDRESS FOCUS
- paste Ergo address -> FOCUS
- loads balance + tokens into focus particle shell
- dims non-focus feed
- HUD: ERG total, token count, named token list with amounts
- CLEAR resets focus

TIMELINE HUD
- chips: MEMPOOL -> ASSEMBLE -> SEALED · FOCUS
- particle counts per stage
- tip card: height, tx count, ERG sum, short block id

TOKEN NAMING UX
- prefers node token name (e.g. AUGERG, ERGUSD-NFT)
- fallback short id xxxx…yyyy
- color fixed per tokenId

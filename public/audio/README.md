# Constellation audio

The 3D Constellation can play ambient music while you explore.

## Your track (optional)

If you **own a license** to play a specific piece (e.g. you purchased the
Interstellar soundtrack for personal use), place the file here:

```
public/audio/stay.mp3
```

Also accepted:

- `stay.ogg`
- `interstellar-stay.mp3`
- `constellation.mp3`

Then open **3D CONSTELLATION** → **MUSIC ON**. The app will loop your file.

## Copyright note

We **cannot** ship or download Hans Zimmer’s *Stay* (Interstellar) with Lumen.
That recording is copyrighted (WaterTower Music / Sony, etc.).

Without a file in this folder, Lumen plays an **original** soft Web Audio
space pad — similar *mood*, different composition.

## Controls

- Button **MUSIC ON / OFF** (desktop panel)
- Key **M**
- Volume slider
